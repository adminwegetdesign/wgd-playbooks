# WGD Playbooks

Practical kits for getting AI working inside a business, from [WeGetDesign](https://wegetdesign.com).

Each playbook puts one step of a WGD Insight into practice. You should be able to download it and get a result the same day.

## How it's organised

The repo follows four stages. Work through them in order; each depends on the one before.

| Stage | Question it answers | Folder |
| --- | --- | --- |
| **Know** | Is your business knowledge written down, owned and current? | [`know/`](know/) |
| **Connect** | Can AI reach the right knowledge, and only that? | [`connect/`](connect/) |
| **Repeat** | Do the tasks you hand to AI run the same way every time? | [`repeat/`](repeat/) |
| **Govern** | Can you show who decided what, and that it works? | [`govern/`](govern/) |

## What's in here

- **Kits:** our own working practice, with client detail removed.
- **Pointers:** third-party resources we have used, with a note on when to use them and when not to. See [`pointers/`](pointers/).
- **Adapted:** kits built on open third-party work, credited and licensed as the source allows.

## Using a playbook

1. Open the stage folder and pick a playbook.
2. Read its README. Each one states who it's for, how long it takes and what it doesn't do.
3. Pick the variant for the tools you already use (SharePoint, Google Drive, Notion or plain markdown).

## What these don't do

They give you the method and a starting point. Deciding what is authoritative in your business, setting up access and testing the result are still your work. If you want help with that, [get in touch](https://wegetdesign.com).
