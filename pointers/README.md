# Pointers

Third-party resources we have used, with our view on when they help and when they don't.

## Rules

- We link; we never copy.
- Every entry says when **not** to use it.
- "Tested by us" is yes or no. "No" is allowed only for official vendor or standards documentation.
- No affiliate links, logos or implied partnerships.
- Every entry is checked quarterly. Anything we can't confirm is removed.
