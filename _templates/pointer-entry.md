# Pointer entry

One row per resource, in the stage file under `pointers/`.

```
| [Name](https://link) | Why we use it, one line | When not to, one line | Yes / No | YYYY-MM-DD |
```

- **Why we use it:** the job it does for us, not the vendor's description.
- **When not to:** the case where it's the wrong choice.
- **Tested by us:** "No" only for official vendor or standards documentation.
- **Last checked:** the date someone confirmed the link works and the advice still holds.
